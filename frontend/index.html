How the Improvement Loop Works in Hindsight

When an engineer clicks 👍 Helpful or 👎 Not Helpful on an incident:

  1. A durable feedback record is stored in SQLite (POST /incidents/{id}/feedback).
  2. Hindsight Memory Update: OpsMind calls hindsight.retain() storing: "Responder feedback on incident {id}: the suggestion '{text}' was helpful."
  3. Future Recall & Reflect Shaping: Next time a similar outage occurs, Hindsight prioritizes memories associated with confirmed positive resolutions, avoiding previously rejected suggestions.

Per-Service Bank Isolation

OpsMind isolates memory into banks per service (opsmind-payments, opsmind-auth, opsmind-notifications). This guarantees that incident vocabulary from one domain (e.g., SMTP latency) never pollutes recall results for an unrelated service (e.g., Database connection pools).

Zero-Dependency Deployment Dual-Mode
